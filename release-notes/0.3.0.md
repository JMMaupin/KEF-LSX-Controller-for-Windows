## Install

Download `KEF-LSX-Controller-{version}.exe` and run it: it offers to install itself in `C:\Program Files\KEF LSX Controller`, with a Start menu shortcut, and starts with Windows. Windows asks for an administrator once. Running a newer file later offers to update the installed copy; your settings (speaker IP, auto USB) are kept.

Uninstall from *Settings → Apps → Installed apps*.

Coming from 0.2.x placed by hand in `C:\Program Files\Kef`: the installer closes it, removes it, and points *Run with Windows* at the new copy.

The executable is not signed: on first launch of a downloaded copy, SmartScreen shows *Windows protected your PC* → *More info* → *Run anyway*.

## Fixed

- **A speaker already on was switched off when the PC started.** With *Auto start USB on boot*, the application sent a USB *toggle*: on a speaker already playing on USB, that meant standby. Now the speaker's state is read on the speaker itself, twice, and USB is sent **only if it is certainly in standby**. A speaker already on — on USB or on any other source — is left alone. No answer or an unexpected state means nothing is sent.
- Same fix on wake from sleep.
- At boot, the connection is retried for two minutes instead of showing an error when the network comes up after the application.
